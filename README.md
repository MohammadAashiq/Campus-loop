
# CampusLoop

A campus lost and found web app that matches lost and found items by keywords and location, and verifies the owner with a secret question. Built for Hack Build'26 (GDG on Campus, CIT Chennai).

## The problem
Lost items usually depend on notice boards and group-chat forwards. There is no search, no matching, and no way to confirm the real owner.

## What it does
- Report a lost or found item with a name, description, location and optional photo
- Suggests the top 3 likely matches with a match score (keyword and location similarity)
- Ownership check: the finder sets a question only the owner can answer
- Counter for items returned

## Live demo
https://mohammadaashiq.github.io/Campus-loop/

## Tech
HTML, CSS and JavaScript (single-file web app, no backend yet)
